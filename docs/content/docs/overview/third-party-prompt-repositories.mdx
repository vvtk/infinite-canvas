# Third-party Prompt Sources

The application includes the following seven sources. Prompt data is read as standard JSON from the [Image Prompts](https://github.com/yukkcat/image-prompts) registry; the original project links identify the upstream content.

| Source | Original project |
| --- | --- |
| Banana Prompt Quicker | https://glidea.github.io/banana-prompt-quicker/ |
| DavidWu GPT Image 2 | https://github.com/davidwuw0811-boop/awesome-gpt-image2-prompts |
| Freestylefly GPT Image 2 | https://github.com/freestylefly/awesome-gpt-image-2 |
| Awesome GPT Image | https://github.com/ZeroLu/awesome-gpt-image |
| Awesome GPT-4o | https://github.com/ImgEdify/Awesome-GPT4o-Image-Prompts |
| YouMind GPT Image 2 | https://github.com/YouMind-OpenLab/awesome-gpt-image-2 |
| YouMind Nano Banana Pro | https://github.com/YouMind-OpenLab/awesome-nano-banana-pro-prompts |

Source management is moving to the administrator-managed server library. Ordinary Settings no longer contains sources or scheduling; browsers read the site API and failed server sync retains the last successful data. This change is [pending acceptance](/docs/progress/pending-test). The table lists initial sources; actual visibility follows administrator settings.

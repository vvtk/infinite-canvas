# Local Development

The main application lives in `web/`. The browser sends AI requests directly to the user's OpenAI-compatible endpoint.

## Start the frontend

```bash
cd web
bun install
bun run dev
```

Open `http://localhost:3000`, then enter your `Base URL`, `API Key`, and model names in Settings. WebDAV remains browser-direct. Public prompts now require the site API and administrator-managed server sources; see [Cloud setup](/docs/development/cloud-sync). With only the frontend running, the shared library reports a load failure while local canvases and private assets remain usable.

## Start the documentation site

```bash
cd docs
bun run dev
```

Common locations:

- Canvas, pages, and interactions: `web/`
- Public prompts: `web/src/services/api/prompts.ts` and `server/src/prompt-sync.ts`
- Documentation content: `docs/content/docs/`
